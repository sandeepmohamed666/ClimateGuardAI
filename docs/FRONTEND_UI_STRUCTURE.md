## Design Language

### Style

- Apple-inspired minimalism
- Light-first interface
- Soft rounded cards (16px radius)
- Glassmorphism only for dialogs
- Consistent 8px spacing system
- Clean typography with generous white space
- Interactive maps and animated charts
- Weather-friendly visual tone with calm sky and cloud-inspired accents

---

### Colors

- Background: `#F8FAFC`
- Background Accent (Weather Sky): `#EEF6FF`
- Sidebar: `#FFFFFF`
- Cards: `#FFFFFF`
- Primary: `#2563EB`
- Success: `#10B981`
- Warning: `#F59E0B`
- Danger: `#EF4444`
- Text: `#111827`
- Secondary Text: `#6B7280`
- Border: `#E5E7EB`

---

### Typography

- Font: Inter
- Headings: 700
- Subheadings: 600
- Body: 400
- Buttons: 600

---

### UI Components

- Sticky top navigation
- Collapsible sidebar
- KPI metric cards
- Interactive climate map
- Line, bar, area, and heatmap charts
- Sortable/filterable tables
- Timeline visualizations
- Progress indicators
- Toast notifications
- Breadcrumb navigation
- Responsive layout (Desktop, Tablet, Mobile)
- Light/Dark mode toggle

---

## Recommended Frontend Stack

- Framework: React + Vite
- Language: TypeScript
- Styling: Tailwind CSS
- UI Components: shadcn/ui
- Icons: Lucide React
- Charts: Recharts
- Maps: React Leaflet / Mapbox GL
- Tables: TanStack Table
- Animations: Framer Motion
- Notifications: Sonner
- Forms: React Hook Form + Zod

This structure is tailored for ClimateGuard AI and aligns with climate analytics, prediction, risk assessment, and explainable AI workflows in a premium light weather-oriented interface.
